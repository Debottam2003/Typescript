# TypeScript Learning Repository

A personal collection of **TypeScript examples, practice files, and learning resources** to help you understand and explore TypeScript concepts progressively.

This repository contains code and examples organized by topic so you can learn step by step.

---

## 📦 What's Inside

This project includes folders and files that demonstrate various TypeScript concepts:

- **01_datatypes** — Examples of basic data types in TypeScript  
- **02_conditionals** — Conditional statements using TypeScript  
- **03_operators** — Operator usage and examples  
- **04_loop** — Looping constructs (`for`, `while`, etc.)  
- **05_utils** — Utility sample functions  
- **06_enums** — Enumeration type examples  
- **07_function** — Functions with types  
- **08_oops** — Object-oriented programming basics  
- **09_generics** — Generic functions and classes  
- **10_promise** — Asynchronous patterns and promises  
- **11_react_ts / TS** — TypeScript with React basics  
- **12_backend** — Backend examples using TypeScript  
- **13_server** — Simple server setups  
- Additional TS files like **copyconstructor.ts**, **test.ts**, etc.

> This structure helps you progress from basics to intermediate topics while tracking your learning history.
